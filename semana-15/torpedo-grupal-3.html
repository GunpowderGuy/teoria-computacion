TORPEDO GRUPAL 3

Temas: ALBA  |  indecibilidad general (ATM, HALT)  |  reduccion con mapeo

1. IDEAS GENERALES

  • Una MT decide L: siempre se detiene. Acepta las cadenas de L y rechaza las que no estan en L.
  • Una MT reconoce L: acepta exactamente las cadenas de L. Si una cadena no esta en L, puede rechazar o entrar en bucle.
  • Si A es indecidible y A se reduce a B, entonces B es indecidible.
  • Si A se reduce a B y B es decidible, entonces A es decidible.

2. ATM Y HALT

ATM  = { <M,W> : M es una MT y M acepta W }
HALT = { <M,W> : M es una MT y M se detiene con input W }

ATM es reconocible

U <M,W> =

Paso 1 : Correr M con W. Si M acepta ACEPTAR.
         Si M rechaza RECHAZAR.

( Si M entra en bucle, U tambien entra en bucle )

ATM es indecidible. Idea de diagonalizacion

Supongamos que H es un decididor de ATM.

D <M> =

Paso 1 : Correr H con input <M,<M>>.

Paso 2 : Si H acepta RECHAZAR.
         Si H rechaza ACEPTAR.

D hace lo contrario de lo que H dice sobre M con su propia descripcion. Al correr D con input <D>, D acepta si y solo si D no acepta <D>. Contradiccion. Por lo tanto H no puede existir.

HALT es indecidible. Reduccion desde ATM

Construimos una MT M' tal:

M' <X> =

Paso 1 : Correr M1 con W1. Si M1 rechaza, entrar en bucle.

Paso 2 : ACEPTAR.
podriamos hacer ATM <M,W>

Paso 1 : Crear M' con M1 y W1 siendo los M y W de input respectivamente.

Paso 2 : Correr el decididor de HALT con input <M', cadena vacia>.
         Si este acepta ACEPTAR. Si este rechaza RECHAZAR.

M' se detiene si y solo si M acepta W. Si HALT fuera decidible, ATM tambien seria decidible. Contradiccion.

ALBA Y REDUCCION CON MAPEO

3. ALBA

ALBA = { <M,W> : M es un Linear Bounded Automaton que acepta W }

Un LBA usa una cinta limitada linealmente por el tamaño del input. Si tiene q estados y g simbolos de cinta, para una entrada de tamaño n hay q*n*g.pow(n) configuraciones posibles: estado, posicion del cabezal y contenido de la cinta.

Si una configuracion se repite, la computacion vuelve a seguir el mismo camino. Entonces no se detendra.

Decididor para HALT_LBA

MTH <M,W> =

Paso 1 : Correr M con W, manteniendo track de las configuraciones visitadas.
         Si alguna configuracion se visita mas de una vez, terminar la simulacion
         y RECHAZAR.

Paso 2 : ACEPTAR.

( Solo se llega al paso 2 si M se detiene por su cuenta )

Decididor para ALBA

Decididor para ALBA <M,W>

Paso 1 : Correr MTH con M y W como inputs. Si este rechaza RECHAZAR.

Paso 2 : Correr M con input W. Si este acepta ACEPTAR.
         Si este rechaza RECHAZAR.

El paso 2 no puede entrar en bucle porque MTH ya garantizo que M se detiene. Por lo tanto ALBA es decidible.

4. REDUCCION CON MAPEO

A es reducible por mapeo a B, escrito A <=_m B, si existe una funcion computable f tal que:

W pertenece A <-> f(W) pertenece B

La funcion transforma los inputs de A en inputs de B y mantiene la respuesta SI/NO.

Forma usual para probar que B es indecidible:
  • Elegir un lenguaje A que ya sabemos que es indecidible, normalmente ATM.
  • Construir una maquina auxiliar M' usando M y W del input.
  • Convertir <M,W> en <M'> mediante una funcion computable.
  • Probar la equivalencia entre pertenecer a A y pertenecer a B.
  • Si B tuviera decididor, podriamos decidir A. Contradiccion.

Importante: para indecibilidad, la funcion solo debe ser computable. No tiene que ser polinomial.

EJERCICIOS DE REDUCCION CON MAPEO

5. LE = { <M> : L(M) es vacio }

Queremos probar que LE es indecidible usando ATM.

Construimos una MT M' tal

M' <X> =

Paso 1 : Correr M1 con W1. Si M1 rechaza RECHAZAR.

Paso 2 : ACEPTAR.

podriamos hacer ATM <M,W>

Paso 1 : Crear M' con M1 y W1 siendo los M y W de input respectivamente.

Paso 2 : Correr el decididor de LE con M' de input.
         RECHAZAR si este acepta. ACEPTAR si este rechaza.

Si M acepta W, M' acepta cualquier X y L(M') no es vacio. Si M no acepta W, M' no acepta ninguna cadena y L(M') es vacio. Por eso la respuesta del decididor de LE se invierte.

6. LReg = { <M> : L(M) es regular }

Usamos el lenguaje no regular {0.pow(n)1.pow(n) : n >= 0}.

MI <X> =

Paso 1 : Si X tiene forma 0.pow(n)1.pow(n), ACEPTAR.

Paso 2 : Correr M1 con W1. Si M1 acepta ACEPTAR.
         Si M1 rechaza RECHAZAR.

podriamos hacer ATM <M,W>

Paso 1 : Crear MI con M1 y W1 siendo los M y W de input respectivamente.

Paso 2 : Correr el decididor de LReg con input MI.
         Si este acepta ACEPTAR. Si este rechaza RECHAZAR.
  • Si M acepta W, MI acepta Sigma* y su lenguaje es regular.
  • Si M no acepta W, L(MI) = {0.pow(n)1.pow(n) : n >= 0}, que no es regular.

Entonces L(MI) es regular si y solo si M acepta W.

7. LEQ = { <M1,M2> : L(M1) = L(M2) }

MInutil <X> =

Paso 1 : RECHAZAR.

Decididor para LE <M>

Paso 1 : Correr el decididor de LEQ con M y MInutil como inputs.
         ACEPTAR si este acepta. RECHAZAR si este rechaza.

L(M) = L(MInutil) si y solo si L(M) es vacio. Si LEQ fuera decidible, LE tambien seria decidible. Por lo tanto LEQ es indecidible.

E_LBA

8. E_LBA = { <M> : M es un LBA y L(M) es vacio }

Prueba por reduccion. Si E_LBA fuera decidible ATM tambien seria decidible.

Construimos una MT M' tal

M' <X> =

Paso 1 : Revisar si X es un historial C0 # C1 # ... # Ck para M1.
         Si X no tiene esa forma RECHAZAR.

Paso 2 : Revisar si C0 es la configuracion inicial de M1 con W1.
         Si no lo es RECHAZAR.

Paso 3 : Revisar si cada C(i+1) se obtiene de Ci usando una transicion
         valida de M1. Si alguna no es valida RECHAZAR.

Paso 4 : Si Ck es una configuracion de aceptacion ACEPTAR.
         De lo contrario RECHAZAR.

( M' es un LBA porque estas revisiones usan espacio lineal respecto de X )
podriamos hacer ATM <M,W>

Paso 1 : Crear M' con M1 y W1 siendo los M y W de input respectivamente.

Paso 2 : Correr el decididor de E_LBA con M' de input.
         RECHAZAR si este acepta. ACEPTAR si este rechaza.
  • Si M acepta W, existe un historial valido que termina en aceptacion. Entonces L(M') no es vacio.
  • Si M no acepta W, no existe ese historial. Entonces L(M') es vacio.

Esto seria un decididor de ATM. Como ATM es indecidible, E_LBA tambien es indecidible.

CHECKLIST PARA EL EXAMEN

  • Definir claramente la maquina auxiliar M' y su input X.
  • Decir que M1 y W1 son M y W incorporados en M'.
  • Explicar que pasa cuando M acepta W y cuando M no acepta W.
  • Revisar si hay que invertir la respuesta del decididor usado.
  • Terminar: si B fuera decidible, A seria decidible. Contradiccion.
