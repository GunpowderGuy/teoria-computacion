Paso3: Si quedan as sin tachar RECHAZAR. De lo contrario ACEPTAR

EAFD , Para decidir este lenguaje , hare el siguiente decididor ( lo llamare D0 ) 


Paso0 : Verificar que el input es un AFD valido.

Paso1 : Eliminar todos los estados no alcanzables
( Un estado es no alcanzable si no existe cadena input, para el cual el automata 
 correspondiente, llegue a dicho estado ) 

Paso2: Si el AFD resultante tiene al menos un estado de aceptación, entonces RECHAZAR. De lo contrario, ACEPTAR


Ahora hare el decididor para EQAFD :

Paso0 : Revisar que el input tiene la forma A,B . Tal que tanto A y B son AFD validos

Paso1 : Construir un AFD que es la intersección de A y B. El AFD resultante será 
llamado I

Paso2: Correr D0 con input I . Si D0 rechaza entonces ACEPTAR.

Paso3: Correr D0 dos veces. Con input A y B respectivamente. Si D0 Acepta en ambas entonces ACEPTAR. 
De lo contrario RECHAZAR

Paso0 : Revisar que el input (llamado G ) es una GLC valida. Si no lo es, RECHAZAR
( esto evita que inputs ilegales causen que los otros pasos acepten de casualidad, o 
tal vez los procesos lopeen forever por input ilegal ) 

Paso1 : Convertir GLC a pushdown automata. El resultado será llamado PD 

Paso2: Eliminar los estados inalcanzables de PD

Paso3: Si PD tiene estados de aceptación , entonces RECHAZAR. De lo contrario ACEPTAR

EXPLICACION : un Pushdown automata o AFD sin estados inalcanzables. Solo tendrá estados de aceptación
si su lenguaje no es el lenguaje nulo
y si no tiene estados de aceptación su lenguaje será el lenguaje nulo.

Como G y PD tienen el mismo lenguaje. Si el lenguaje de PD es lenguaje nulo entonces el de G también.
Si el lenguaje de PD no es lenguaje nulo, el de G tampoco.
